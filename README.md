# DM-SPAM

Panel de consola para Termux con interfaz neon roja y dos herramientas de Discord integradas.
## Funciones

| Opcion | Nombre   | Descripcion |
|--------|----------|-------------|
| 1      | DM-SPAM  | Rafaga masiva de mensajes directos a una ID |
| 2      | CHAT     | Chat en vivo por consola con una ID (con descarga de multimedia e historial) |
| 3      | INFO     | Requisitos, token e intents necesarios |
| 0      | SALIR    | Cerrar el lanzador |
